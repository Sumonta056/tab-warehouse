# Glossary

**Root folder**: The bookmark folder that holds everything the warehouse shows. Its child folders are the Folders.

**Folder**: A direct child folder of the Root folder. A Folder is an item in the sidebar and has its own page.

**Section**: Any folder inside a Folder, at any depth. A Section shows as a header on the Folder page.
_Avoid_: subfolder, sub-section, part, group

**Parent section**: The Section that holds another Section. A Section directly inside a Folder has no Parent section.

**No section**: The links that are directly inside a Folder and not in a Section.

**Unsorted**: The links that are directly inside the Root folder. Unsorted shows as a Folder, but it has no Sections.

**Link**: One bookmark with an address. A Link belongs to exactly 1 Folder or Section, or to Unsorted.
